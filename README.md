# Parameptrix EQ

**A creative, character-driven parametric EQ for macOS — VST3, CLAP + Audio Unit, Apple Silicon.**

### ⬇︎ [Download the latest installer](https://github.com/jamcgrath/parameptrix-eq/releases/download/v0.2.1/Parameptrix-EQ-0.2.1.pkg)

Or grab it from the [Releases](https://github.com/jamcgrath/parameptrix-eq/releases) page.
The `.pkg` is signed with a Developer ID and notarized by Apple, so it installs with no Gatekeeper
warnings.

**Install:** open the `.pkg`, follow the installer (it drops the VST3, CLAP + Audio Unit into
`/Library/Audio/Plug-Ins`), then rescan plug-ins in your DAW and add **Parameptrix EQ** to a track.

**Requires:** macOS on Apple Silicon (arm64).

---

Sixteen bands across thirteen filter types — including comb filters with switchable polarity,
sung-vowel formants, asymmetric bells, a spectrum tilt and a sharper-than-a-bell resonance — over a
multiband saturator (Warm / Tube / Hard / Bite, per zone or global, pre- or post-EQ) and a bit
crusher. Four curve macros move every band at once, and Creative mode fits the bands to a response
you draw by hand. Live analyzer, A/B, JSON presets, Dark and Light themes, UI at 75–200 %.

[Download page](https://jamcgrath.github.io/parameptrix-eq/) · [User guide](https://jamcgrath.github.io/parameptrix-eq/guide.html)

This repository hosts the download page and releases only; the plugin is built from scratch in Rust
and is not a port or reverse-engineering of any existing product.
